# AnimeVerse 🎬

A modern, full-stack anime discovery and tracking web application built with React, Vite, and Tailwind CSS, featuring cloud-synced watchlists via Supabase.

---

## ✨ Key Features

- **Trending & Airing Anime:** Real-time discovery powered by the Jikan API.
- **Cloud-Synced Watchlist:** 1-click bookmarks backed by Supabase with Row-Level Security (RLS).
- **User Authentication:** Secure signup, login, and session persistence via Supabase Auth.
- **Rich Anime Details:** Covers synopsis, characters, trailers, genres, and broadcast data.
- **Live Search & Filters:** Fast title search, pagination, and genre-based browsing.
- **Resilient Fetching:** Built-in retry logic with exponential backoff to circumvent API rate limits (HTTP 429).
- **Responsive Dark UI:** Cinema-inspired layout styled with Tailwind CSS.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS, React Icons
- **Backend & Database:** Supabase (PostgreSQL, Auth, RLS)
- **Data Source:** Jikan API (MyAnimeList)
- **Deployment:** Vercel
